# 잇룸 디자인 시스템

> 구조는 Threads, 피부는 Mobbin. 원문 참고: `reference-mobbin.md`

## 0. 한 줄 방향
흰 갤러리 벽에 걸린 소식들. 색은 이미지와 링크 썸네일만 가지고, 나머지는 잉크와 종이의 농담으로만 위계를 만든다. 모든 누를 수 있는 것은 필(pill)이고, 그림자는 없다.

## 1. 색 토큰

기본값은 시스템 설정을 따르고(`prefers-color-scheme`), 헤더 토글로 수동 변경한다. 수동 선택은 `localStorage`에 저장한다. 두 테마는 같은 사다리 구조를 반전한 것이다.

| 토큰 | Light | Dark | 용도 |
|---|---|---|---|
| `--canvas` | #ffffff | #141414 | 페이지 배경 |
| `--canvas-soft` | #f3f3f3 | #1f1f1f | 플로팅 nav 필, 소프트 필, 강조 면 |
| `--field` | #f0f0f0 | #232323 | 입력창 채움 |
| `--hairline-soft` | #f0f0f0 | #232323 | 카드 외곽선, 글 사이 구분선 |
| `--hairline` | #e0e0e0 | #333333 | 아웃라인 버튼 테두리, 강한 구분 |
| `--ink` | #141414 | #f5f5f5 | 제목, 본문, CTA 필 채움 |
| `--ink-soft` | #262626 | #e0e0e0 | 보조 강조 |
| `--on-ink` | #ffffff | #141414 | ink 필 위 글자 |
| `--text-muted` | #707070 | #9a9a9a | 시각, 보조 문구, 태그 |
| `--text-faint` | #adadad | #6b6b6b | 플레이스홀더, 각주 |
| `--accent` | #0066ff | #4d8dff | **본문 하이퍼링크 전용** |
| `--destructive` | #d92d20 | #f97066 | 삭제 확인 버튼 한 곳 |
| `--overlay` | rgba(115,115,115,0.56) | rgba(115,115,115,0.56) | 이미지 위 배지 |
| `--scrim` | rgba(0,0,0,0.5) | rgba(0,0,0,0.7) | 다이얼로그 뒤 |

- 악센트 블루는 글 본문 안의 `<a>` 글자색에만 쓴다. 버튼, 칩, 배지, 포커스 링 어디에도 쓰지 않는다.
- 포커스 링은 2px `--ink`.
- 컴포넌트 안에서 hex를 직접 쓰지 않는다. 항상 토큰.
- Tailwind v4 `@theme`에 위 토큰을 등록하고, shadcn/ui 변수(`--background`, `--foreground`, `--muted`, `--border`, `--ring` 등)는 이 토큰에 매핑한다.

## 2. 서체

**Pretendard Variable** 단일 서체. 한글과 Latin을 하나로 처리하고 가변 굵기 축을 가져서 Mobbin의 Saans 원칙(652/456/300)을 그대로 옮길 수 있다. 자간 0, 문장형.

| 토큰 | 크기 | 굵기 | 행간 | 용도 |
|---|---|---|---|---|
| `display` | 40 | 650 | 1.0 | 로그인 화면 로고 "잇룸" |
| `heading` | 24 | 650 | 1.25 | 로그인 카드 제목, 빈 상태 제목 |
| `title` | 16 | 600 | 1.3 | 작성자 이름, 버튼 라벨, 링크 카드 제목 |
| `body` | 16 | 450 | 1.6 | 글 본문 (한글은 Mobbin의 1.38보다 넉넉히) |
| `body-light` | 16 | 300 | 1.6 | 로그인 안내문, 빈 상태 설명 |
| `body-sm` | 14 | 450 | 1.5 | 링크 카드 설명, 에디터 도움말 |
| `label` | 12 | 600 | 1.33 | 태그 칩, 배지 |
| `caption` | 12 | 450 | 1.33 | 시각, 도메인, 각주 |
| `code` | 14 | 400 | 1.6 | 인라인 코드, 코드블록 (JetBrains Mono) |

- 본문 최소 16px. 모바일 iOS 자동 확대 방지.
- 코드블록만 JetBrains Mono. 그 외 어디에도 모노스페이스를 쓰지 않는다.
- 로고 "잇룸"은 별도 워드마크 없이 `display` 토큰 텍스트. 마침표 없음.

## 3. 간격, 곡률, 고도

- 간격: 4 / 8 / 12 / 16 / 24 / 32 / 48. 피드 글 내부 패딩 16(모바일) / 24(md+). 글 사이 구분선 위아래 여백 없음(패딩이 여백 역할).
- 곡률: `sm` 16 (이미지 타일, 링크 카드, 입력창, 다이얼로그) / `md` 24 (로그인 카드) / `full` (버튼, 칩, 배지, nav 필, 아바타).
- 고도: 그림자 없음. 0 flat / 1 `--canvas-soft` 채움 / 2 1px `--hairline-soft` 외곽선 / inverse `--ink` 채움. 예외 없음. 다이얼로그도 흰 면 + scrim으로만 띄운다.

## 4. 레이아웃

- 컬럼: 최대 640px 중앙. 모바일은 전폭, 좌우 16px. `md` 이상 24px.
- 브레이크포인트: sm 640 / md 768 / lg 1024. 검증 뷰포트 360, 390, 768, 1024, 1440.
- 세로 높이는 `min-h-dvh`. 100vh 금지.
- 헤더 높이 56px + 상단 오프셋 12px. 본문은 헤더 아래 `padding-top: 80px`.

## 5. 컴포넌트

### 5.1 앱 헤더 (Facebook 구성, `components/layout/app-header.tsx`)
- 화면 상단 전체 폭 sticky, 높이 56px, `--canvas` 면 + 아래 1px 헤어라인.
- 왼쪽: 노을 그라데이션 "잇" 로고 타일 + "잇룸" 워드마크(640px 미만에서는 타일만).
- 가운데: 홈·쓰기 두 탭(모든 폭에서 표시, 모바일 하위 화면에서는 숨김). 탭 폭은 모바일 56px, `sm` 이상 96px. 선택된 탭은 아래 3px ink 밑줄. `/me`, 글 상세·수정에서는 어느 탭도 선택되지 않는다.
- 오른쪽: 테마 전환(`sm` 이상), 프로필 메뉴. 모두 40px 원형 `--canvas-soft` 버튼.
- 프로필 메뉴: 이름 영역(아바타 + 이름 + 소유자/회원, 클릭 없음) → "내 소식" 항목(`/me`, 현재 페이지면 `aria-current`) → 구분선 → 다크 모드 → 구분선 → 로그아웃. 항목 높이 44px 이상.
- 내 소식은 탭으로 두지 않는다. 아바타와 "나"가 두 번 보이지 않도록 모든 폭에서 프로필 메뉴 안에 둔다.
- 본문: 페이지 바탕 `--page` 위에 최대 680px 컬럼, 카드 사이 12px 간격. 640px 미만에서는 카드가 화면 폭을 채우고 위아래 헤어라인만 둔다.

### 5.2 post-row (피드 글 카드, Facebook 구성)
- 글마다 독립 카드. 머리: 40px 노을 아바타 + 이름(위) / 시간(아래) + 오른쪽 ⋯ 메뉴. 본문은 카드 폭 전체.
- 아래 도식은 초기 Threads 구조 기록.
```
┌────────────────────────────────────────────┐
│ (아바타 36)  이름 · 3시간 전         [⋯]  │  ← ⋯는 owner에게만
│              본문 body 450                   │
│              [이미지 타일 16px 곡률]         │
│              ┌ 링크 카드 (hairline-soft) ┐  │
│              │ 썸네일 │ 제목 / 설명 / 도메인│
│              └──────────────────────────┘  │
│              (AI) (Next.js) (오픈소스)       │  ← 태그 칩
├──────────── 1px hairline-soft ─────────────┤
└────────────────────────────────────────────┘
```
- 카드 없음. 글과 글은 1px `--hairline-soft`로만 구분.
- 아바타: 36px 원형, `--canvas-soft` 채움에 이름 첫 글자. 이미지 없음.
- 이름 `title` 650, 시각 `caption` `--text-muted`, 사이에 "·".
- 본문: `body` 450. 링크는 `--accent` 글자색, 밑줄 없음, hover 시 밑줄.
- 이미지 1장: 컬럼 폭, 16px 곡률, 최대 높이 520px `object-cover`, 클릭 시 원본 다이얼로그. 2장 이상: 가로 스크롤 스냅, 각 타일 높이 240px.
- 링크 카드: 1px `--hairline-soft` 외곽선, 16px 곡률. 모바일은 썸네일 위(16:9), 텍스트 아래. `sm` 이상 썸네일 좌측 120px 정사각, 텍스트 우측. 제목 `title`, 설명 `body-sm` `--text-muted` 2줄 말줄임, 도메인 `caption` `--text-faint`.
- 태그 칩: `button-pill-soft` 축소판. `--canvas-soft` 채움, `label` 600, 높이 28px, 좌우 12px. 클릭 시 `/?tag=`. 활성 태그(현재 필터)는 `--ink` 채움 + `--on-ink`.
- owner 메뉴 [⋯]: 40px 원형 아이콘 버튼, hover 시 `--canvas-soft`. 드롭다운은 흰 면 + `--hairline-soft` 외곽선 + 16px 곡률. 항목: 수정 / 삭제(`--destructive` 글자).

- 빠른 버튼 아이콘만 `--tint-photo`, `--tint-link`, `--tint-tag` 색을 쓴다.
- 아래는 초기 기록.

### 5.4 버튼
- `button-primary`: `--ink` 채움, `--on-ink` 라벨 `title` 600, 높이 40px, 좌우 16px, `rounded-full`. 로그인, 게시, 저장.
- `button-outline`: `--canvas` 채움, `--ink` 라벨, 1px `--hairline`, 높이 40px. 취소.
- `button-pill-soft`: `--canvas-soft` 채움, 테두리 없음. 태그 칩, 툴바 보조.
- `button-icon`: 40px 원형, 투명, hover `--canvas-soft`. 헤더 토글, [⋯], 툴바.
- 파괴 버튼은 삭제 확인 다이얼로그 안에서만 `--destructive` 채움.
- 눌림 피드백: 불투명도 0.8, 120ms. 크기 변화 없음(레이아웃 흔들림 금지).
- 로딩 중: 스피너 + 비활성. 라벨은 유지해 폭이 변하지 않게.

### 5.5 입력창
- `--field` 채움, 테두리 없음, 16px 곡률, 높이 44px, 좌우 16px. 플레이스홀더 `--text-faint`.
- 포커스: 2px `--ink` 링(`ring-offset` 0).
- 라벨은 항상 보이는 텍스트(플레이스홀더만 두지 않음). 에러는 필드 아래 `body-sm`, 아이콘 + 문구.

### 5.6 로그인 화면
- 캔버스 중앙 정렬. 로고 "잇룸" `display` 650. 안내 문구 없음. 배경은 노을 하늘 유체(`components/auth/sky-backdrop.tsx`), 카드는 반투명 유리.
- 카드: `--canvas` 면, 1px `--hairline-soft`, 24px 곡률, 패딩 32px, 최대 폭 400px. 모바일에서는 카드 테두리 없이 캔버스에 직접(폭 360 대응).
- 이메일, 비밀번호(표시 토글), `button-primary` 전폭 "로그인", 아래 `caption` `--text-muted` "비밀번호를 잊으셨나요?" 밑줄 링크.
- Mobbin의 auth 카드와 같이 요소가 한 컬럼에 세로로 쌓이고 장식 없음.

### 5.7 에디터 (/write, /edit)
- 헤더 nav-pill은 그대로. 본문 컬럼 안에 compose-row 확장 형태: 아바타 + 에디터 영역.
- 에디터 영역: 테두리 없음, 플레이스홀더 "무슨 소식인가요?" `--text-faint`. 최소 높이 160px, 자동 확장.
- 툴바: 에디터 위 sticky. `button-icon` 8개(굵게, 기울임, 취소선, 인라인 코드, 코드블록, 링크, 목록, 이미지)를 `--canvas-soft` 필 안에 가로 배치. 모바일에서 가로 스크롤(스크롤바 숨김). 활성 상태는 `--ink` 채움 아이콘 반전.
- 태그 입력: 에디터 아래 `--field` 입력창 "태그 추가 (Enter)". 입력된 태그는 칩으로 좌측에 쌓이고 × 로 제거.
- 하단 액션 바: 우측 정렬 `button-outline` "취소" + `button-primary` "게시". 모바일에서는 화면 하단 sticky, 캔버스 채움 + 상단 hairline.
- 이미지 업로드 중: 에디터 안에 16px 곡률 `--canvas-soft` 스켈레톤 타일을 먼저 삽입해 레이아웃 이동 방지.

### 5.8 다이얼로그, 토스트, 빈 상태, 스켈레톤
- 삭제 확인 다이얼로그: `--canvas` 면, 16px 곡률, 패딩 24px, 최대 폭 360px. 제목 `heading`, 설명 `body-sm` `--text-muted`, 버튼 `button-outline` 취소 + `--destructive` 삭제. 뒤는 `--scrim`.
- 토스트: 하단 중앙, `--ink` 채움 + `--on-ink` 글자, `rounded-full`, 3초 후 자동 닫힘. `aria-live="polite"`.
- 빈 피드: 아바타 자리 없이 중앙 `heading` "아직 소식이 없습니다." + `body-light` 안내. 안내 문구는 "위 쓰기 버튼으로 첫 소식을 남겨보세요." 별도 버튼 없음.
- 무한 스크롤 로딩: post-row 형태 스켈레톤 2개(`--canvas-soft` 블록). 끝에 도달하면 `caption` `--text-faint` "마지막 소식입니다." 중앙.

## 6. 모션
- 지속시간 150~250ms, ease-out 진입 / ease-in 퇴장. 500ms 초과 금지.
- transform, opacity만 애니메이션. width/height 금지.
- 피드 새 묶음 로드 시 항목 30ms 간격 stagger fade-in(위로 8px 이동).
- 다이얼로그: scale 0.96 → 1 + fade, 200ms.
- 테마 전환: 색 전환 애니메이션 없음(깜빡임 방지, 즉시 전환).
- `prefers-reduced-motion` 시 모든 전환 0ms.

## 8. Do / Don't (잇룸 적용판)
- Do: 색은 이미지, OG 썸네일, 본문 링크에만. 나머지는 잉크 농담.
- Do: 누를 수 있는 모든 것은 `rounded-full`. 사각 버튼 없음.
- Do: 구분은 1px hairline. 카드 박스로 글을 감싸지 않는다.
- Don't: 그림자, blur, 그라데이션, 색 배경 밴드.
- Don't: 이모지 아이콘. Lucide 1.5px 스트로크 하나로 통일.
- Don't: 입력창 테두리. 포커스 링만.
- Don't: 자간 조정, 대문자 강제.
